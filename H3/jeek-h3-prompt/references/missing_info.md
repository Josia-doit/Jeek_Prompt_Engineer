# 缺失信息追问闸门（missing_info）

编写 H3 提示词前，若用户请求缺少下列必要信息，应主动追问补全，而非自行假设关键事实。先判定模式，再按需追问；可合并为一组问题一次问清。

## 1. 先判定模式所需的资产

| 用户给了 | 可能模式 | 还需确认 |
| --- | --- | --- |
| 纯文字 | T2VA | 时长、风格、是否要声音 |
| 一张图（说是开头） | I2VA | 确认它是首帧；时长 |
| 两张图（说是开头+结尾） | FL2VA | 确认首尾对应关系；时长 |
| 一张图（说是结果） | L2VA | 确认它是尾帧；前置情节意图；时长 |
| 参考图/视频/音频 + 要求保特征 | Ref2VA | 每条资产的角色（见下） |

若资产与模式对不上（如给了首尾帧却说要 I2VA），向用户澄清真实意图再继续。

## 2. 基础模式必问项

- **目标时长**：对齐指令行里的 `S.SS`、镜头切镜时间都依赖它；用户没说则追问（如「这段视频大概几秒？」）。
- **风格**：T2VA 无参考图时需用户指定视觉风格（`live-action`/`2D-animated`/`3D CG`/`cinematic` 等）；有参考图则从图推导，可不问。
- **声音需求**：是否需要 `overall_soundscape`（环境/动作声）与 `non_diegetic_music`（背景配乐）？全静音用 `N/A`。用户没提则默认给合理音景，但可顺带确认。
- **关键帧角色**（I2VA/FL2VA/L2VA）：明确每张图是首帧、尾帧还是关键帧锚点，错误归属会导致对齐指令行写错。

## 3. Ref2VA 必问项

- **每条参考资产的角色**：图/视频/音频分别承担什么？是定义主体外观（→ `<Subject N>`）、作具体帧锚点（→ `<Picture N>`）、作剪辑/续写源（→ `<Video N>`）、还是复制/引用声音（→ `<Audio N>`）？
- **保留程度预期**：用户希望被参考内容 `fully_preserved` / `partially_preserved` / `attribute_transfer` / `weak_reference`（可视），或 `fully_copy` / `partially_copy` / `reference` / `weak_reference`（音频）？不明确时在 `retention_analysis` 按最合理判断并标注。
- **主体身份与说话人**：哪些参考主体会发声？需要 `(Sx)` ID 与音色/语言说明吗？音频资产是否绑定某个说话人（`<Subject N> (Sx)`）？
- **任务类型**：编辑 / 续写 / 参考生成 / 音频复用，组合后写入 `summary` 前缀。

## 4. 通用必问项

- **对话/歌词语言与内容**：有台词或歌词必须拿到原文（含语言），否则无法写 `<d>[Language] ...</d>`；缺失则追问原句。
- **画面可见文字**：图中若有需保留的标牌/字幕/霓虹文字，问清原文。
- **禁止内容**：用户是否要求不出现某些元素（避免模型自由发挥跑偏）？

## 5. 追问的两种呈现方式

- **WorkBuddy 等支持交互问询的 Agent**：直接用 AskUserQuestion 等工具抛结构化问题（选项 + 填空）。
- **其他 Agent / 纯文本环境**：以编号清单一次性列出待确认项，例如：

```text
在写 H3 提示词前，请确认：
1. 模式：你给了首尾两张图 → 我按 FL2VA 处理，对吗？
2. 时长：目标视频几秒？（用于对齐指令行与切镜时间）
3. 声音：需要背景配乐吗？还是全程环境声即可？
4. 台词：角色有没有具体要说的话？原文是什么语言？
```

补全后再进入 `base_guide.md` / `ref_guide.md` 的编写流程。
